# AGENTS.md

## Project

- Name: 3d-home
- Description: A web-based 3D smart home solution showcase system for everyday smart users.

## Communication Rules

- Explain every answer in plain language that a non-expert can understand.
- Avoid unnecessary jargon. If technical terms are needed, explain what they mean.
- State what you changed, why you changed it, and how the user can verify it.
- Keep responses concise, but include enough context for the user to follow.

## File Safety Rules

- Do not randomly delete files.
- Do not remove, overwrite, or revert existing user work unless the user explicitly asks for it.
- Before making file edits, inspect the relevant files and understand the current project structure.
- Keep changes focused on the user's request.
- If a potentially destructive action is needed, ask the user for confirmation first.

## Development Guidance

- Prefer simple, maintainable implementation choices.
- Match the existing project style once the project has code.
- Build user-facing features with ordinary smart home users in mind: clear visuals, easy controls, and understandable labels.
- For 3D or visual pages, verify that the page renders correctly before reporting completion whenever possible.
