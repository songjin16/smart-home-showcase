# 智能家居案例展示系统

这是一个前端展示网站，当前主要包含案例首页、服务地图、案例详情、场景演示和产品点位介绍。

## 本地查看

1. 安装依赖：

   ```bash
   npm install
   ```

2. 复制环境变量示例文件为 `.env.local`，再填写高德地图配置：

   ```bash
   cp .env.example .env.local
   ```

3. 启动开发服务：

   ```bash
   npm run dev
   ```

4. 打开终端里显示的网址。

## 上线前检查

先运行：

```bash
npm run build
```

如果构建成功，说明项目可以生成上线文件。

再运行：

```bash
npm run preview
```

然后检查：

- 首页能打开
- 服务地图能打开
- 案例详情、场景演示和产品点位介绍能进入
- 电脑和手机宽度下页面没有明显错位
- 高德地图在配置好环境变量后能正常显示

当前案例图片文件较大，第一版可以先上线，后续应优先做图片压缩和加载速度优化。

## 推荐上线方式

第一版推荐先用 Vercel 发布，按 [DEPLOYMENT.md](./DEPLOYMENT.md) 的步骤操作。
